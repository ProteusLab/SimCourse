# ToyISA Interpreter

## Цель

Реализовать симулятор (интерпретатор) ЦПУ. На вход — бинарный файл с кодами инструкций. Программа завершается системным вызовом exit.

## Требования

Минимальные требования для сдачи (1 балл из 2):

1. Реализация симулятора (интерпретатора) ЦПУ. На вход — бинарный файл с кодами инструкций. Программа завершается системным вызовом exit.
2. Тесты на ВСЕ инструкции из спецификации системы команд.
3. Кэширование декодированных инструкций.
4. Успешный запуск теста: программа на подсчёт n-ого числа Фибоначчи.

Дополнительный балл даём за реализацию threaded code.

## Порядок и срок сдачи

1. Очная сдача.
2. Беседа по выполненной задаче.
3. Код, залитый на GitHub/GitLab, с минимальной системой сборки.

Дедлайн — 5.10.

## Критерии оценивания

- 1 балл — выполнены минимальные требования (пункты 1–4).
- +1 балл — реализован threaded code.
