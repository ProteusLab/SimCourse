# ToyISA Microasm

## Цель

Написать на Ruby программу, которая позволяет описывать машинный код в виде, похожем на ассемблер.

## Требования

- Каждая строка этого «ассемблера» является вызовом метода Ruby.
- В результате работы микроассемблера создаётся файл с бинарными кодами инструкций.
- Этот файл читается вашим интерпретатором и выполняется.

Задачка со *: поддержка меток.
